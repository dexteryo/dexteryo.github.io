№ 01

Principles

Lightness is the luxury. A display face set at 300 says the argument does not need to raise its voice; a bold headline is a system shouting to be believed. Atelier earns financial-grade trust the way a good magazine does — confident type, generous margins, and every claim answered by a citation.1

The page is a broadsheet, the paragraph is a book. The shell spans the full width of the screen, with a sticky contents rail on wide displays. Diagrams, tables, stat strips and service directories use every column; prose alone keeps a 70-character measure so it still reads like a book.

Whitespace is the structure. Sections are separated by space and a folio number, not by rules or boxes. Where a line is needed it is a hairline; the double rule appears only where print tradition put it — under the masthead, over the colophon, closing a sum.

One accent, many pigments. Oxblood is the printer's second colour: the drop cap, the hanging quotation mark, one emphasised word, the verdict label, a proposed change. Diagrams get their own case of pigment inks — indigo, plum, verdigris, ochre, sienna, moss — and every ink means one thing, declared in the legend.

Architecture is drawn, not described. A flow narrated step by step is also drawn as a native SVG plate, with numbered steps tied to the walkthrough beneath it. Directional motion — marching dashes and a travelling packet on the hot path — shows which way the data goes, and stops for readers who ask for reduced motion.

1. The lineage: Stripe Press, The Paris Review, FT Weekend, Economist print charts, Tschichold's Penguin composition rules, the engineering plates of an architectural monograph. README.md — Lineage

№ 04

Architecture diagrams

Native SVG plates in pigment inks. Node kinds and route kinds each carry one ink; zones draw boundaries as dashed rules; numbered steps tie the plate to the walkthrough under it. The hot path carries marching dashes and a travelling packet — directional motion only, disabled under prefers-reduced-motion. Plates sit between a strong rule and a hairline, like every other Atelier figure, and scroll inside themselves on narrow screens.

  1. A client submits a top-up to the API gateway with an Idempotency-Key header.
  2. The gateway verifies the bearer token with auth-service — control plane, cached for 60 s.
  3. The gateway routes the request to wallet-service, the only writer of wallet balances.
  4. wallet-service reserves the key in wallets and creates a payment with the card PSP.
  5. The PSP confirms by webhook to webhook-handler, which verifies the signature.
  6. webhook-handler appends the double-entry pair to the journal.
  7. wallet-service credits the wallet and publishes wallet.funded to funding.events.
  8. The proposed recon-worker compares wallets with the journal nightly; poison events go to funding.dlq.

Decision record — .atl-adr

ADR-014 · 2026-09-14 accepted

Reconcile wallets nightly with a dedicated worker

Context

Wallet balances and the journal drift on roughly 2% of wallets per month. Reconciliation is a manual month-end spreadsheet, so a divergence can stay hidden for thirty days.

Decision

Run recon-worker nightly at 02:00 UTC as a Lambda reading replicas of wallets and journal, alerting on any per-wallet gap over €1 and dead-lettering unparseable events.

Consequences

  • Detection window falls from 30 days to 1.
  • Read replicas only — no write path into money.
  • A new on-call duty for the DLQ.
  • Replica lag can flag false gaps near midnight.

Callouts — .atl-callout note / warn / risk / decision

Replica lag is bounded at 5 s in normal operation; the worker reads with a 10-minute safety margin.

The PSP's sandbox does not emit requires_action; test 3-D Secure paths in staging only.

A second writer of wallet balances would make reconciliation unsound. Any new writer needs its own ADR.

Alert threshold is €1 per wallet, not a percentage — small wallets matter as much as large ones.

Code with a filename strip — .atl-code

recon/compare.sqlSQL
-- gaps above one euro, in cents
SELECT w.wallet_id, w.balance - j.total AS gap
FROM   wallets w JOIN journal_rollup j USING (wallet_id)
WHERE  ABS(w.balance - j.total) > 100
AND    w.updated_at < now() - '10 minutes'::interval;
№ 06

Panel mode

The Economist/FT print-data idiom: the same warm paper, hairline horizontal rules, no cards and no boxes. Numbers are very large and very light; statuses are solid squares in the semantic ink; chips are small-caps text with a thin coloured underline. Panels flow into as many columns as the width allows.

№ 07

Charts & fallbacks

Charts are inline SVG using the viz palette in order, between hairlines like a plate in a book, captioned in small caps and numbered. For diagram shapes the native grammar does not cover — entity-relationship, gantt — pre-render Mermaid to static SVG with mermaid-config.json and keep the DSL in a <details>.
