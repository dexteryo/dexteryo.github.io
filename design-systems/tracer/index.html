00 / Executive verdict

The hero answers; the sections prove

A Tracer page opens with the conclusion: kicker, uppercase title with one accent phrase, stand-first, a filled verdict banner, and the impact strip. Identifiers sit in mono — EventConsumer — and tickets ride chips: CLEV-123 verified degraded failing.

GAP

Where it dies

The decline never leaves clevergift-api — the emit call does not exist.

CONTROL

The control case

Approved cards emit normally on the same path, which isolates the gap to one branch.

Root gap — clevergift-api

01 / Trace diagram

The signature: where the signal dies

Boxes carry a kind (what it is) and a state (what it did); the fail edge stops visibly short of the stage it never reached. New in v2: zones, numbered steps keyed to the walkthrough, a packet on the route the argument turns on, and the annotation bubble — a light card naming the change that lands at that hop. Hover a legend route to isolate it.

  1. The recipient verifies the OTP; the request reaches clevergift-api normally.
  2. On decline, no event is emitted — the fail edge terminates inside the service.
  3. The audit control path writes on both outcomes, proving everything after the gap is healthy.
02 / Sequence

The same death, in time order

v2 draws sequences natively: actor boxes reuse the trace vocabulary, lifelines dash down, activation bars mark work, and the failing message dies mid-lane with a .bad label — exactly like a trace.

03 / State machine

States are pills; transitions are routes

States tint by meaning (ok, warn, bad, accent); transition labels carry a panel-coloured halo so they survive crossing lines. Start and final pseudo-states follow UML.
