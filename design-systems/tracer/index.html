01 / Tokens

Colour is meaning

Every value is a --trc-* custom property. The accent points; the other hues are states and routes — red fails, green is proven, yellow degrades, teal derives, purple runs out-of-band. A hue used decoratively is a defect.

--trc-bgground
--trc-panelsurface
--trc-panel-2raised
--trc-accentpoints · nominal route
--trc-critfailing · lost
--trc-okproven · clean
--trc-warndegraded · attention
--trc-tealsecondary · derived
--trc-purpleasync · out-of-band

Dark is the identity; the light counterpart ships in every output via the @media block and data-theme overrides. Code blocks stay dark in both.
