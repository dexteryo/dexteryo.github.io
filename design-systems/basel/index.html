01

Principles

The grid is the argument. Alignment is not styling; it is the visual proof that the document was composed, not accumulated. Every element sits flush-left on the column grid, and the grid may be shown (.bsl-grid-visible) because there is nothing to hide.

Type is the only ornament. Hierarchy comes from size and weight alone — a 64px headline against a 10px letterspaced label needs no colour, no rule, no icon to explain which is which. There are no italics anywhere in this system.

One red, two meanings, zero decoration. Pantone 186 is both the key emphasis and the critical state. When you see red, either something matters most or something is wrong — the reader never has to ask which colour system applies, because there is only one.

Objectivity is the tone. Müller-Brockmann called the style objective-informative: the designer's hand disappears behind the structure. A Basel report should read as if the facts arranged themselves.

Müller-Brockmann, Grid Systems in Graphic Design · 1981

03

Typography

One family for everything — Helvetica Neue with system fallbacks — and monospace reserved for evidence and machine values. Hierarchy is size and weight only. No italics exist in this system: the stylesheet forces em and i upright and bold.

The nightly comparison job keys on wallet ID and alerts on any per-wallet gap over €1:

SELECT wallet_id, float_cents - journal_cents AS gap
FROM   reconciliation_snapshot
WHERE  ABS(float_cents - journal_cents) > 100;

Reconcile the mirrors nightly, not monthly.

The drift window is the exposure. A nightly three-way check (float, wallet ledger, journal) shrinks the maximum undetected divergence from thirty days to one.

  1. Add a scheduled comparison job keyed on wallet ID.
  2. Alert on any per-wallet gap over €1.

The slab above is the system's one inversion: black field, white type, red label. Because nothing else on the page inverts, it cannot be missed — which is why a second inversion anywhere is a defect.

05

Panel mode

For dashboards, risk registers, and status pages: a Müller-Brockmann poster grid. Cells share 1px black rules like a printed table, values are huge and tight, status markers are hard squares, and chips are letterspaced text over a 2px semantic underline. No fills, no pills, no shadows.

06

The visible grid

Add .bsl-grid-visible to any container to expose the 12-column rules — the working-draft view. The grid may stay in a final document; it is honest.

Working draft. Every flush-left edge in this box sits on a column rule. If an element does not land on the grid, it is off the system.

07

Diagrams

Mermaid, themed through mermaid-config.json: white ground, black lines, red reserved for the one path or state that matters. Pre-render to static SVG for self-contained output and keep the DSL beside the figure in a <details> block. Every figure gets a flush-left numbered caption.

npx -y @mermaid-js/mermaid-cli -i flow.mmd -o flow.svg --configFile mermaid-config.json
