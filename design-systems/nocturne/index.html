01 —

Principles

Borders carry elevation. Hierarchy comes from the surface scale — ground, surface, raised — separated by 1px hairlines. The only shadow in the whole system is the card's one-pixel top inner highlight: machined edge light, not elevation theatre. If a surface needs to feel higher, it steps up the scale; it never floats.

One accent, spent carefully. A restrained indigo marks what is actionable or singular: links, section numbers, the verdict bar, focus rings, at most one emphasis per page. When everything glows, nothing does — so nothing glows.

Machine truth wears the machine face. Every metric, timestamp, ID, and piece of evidence is monospace with tabular numerals. Evidence is a visual element: claims cite their source in a bordered ref pill FundsRouter.java:214 inline with the claim.

Dark is the default, not a skin. The default token block is dark; light is the counterpart. That ordering forces the discipline dark UI needs — no thin display type, muted text that still clears 4.5:1, semantic colours tuned for a near-black ground.

Portability is a hard constraint. System font stacks only, no webfonts, no external requests. Output must survive a sandboxed artifact viewer, a ticket attachment, and a printer.

The comparison job keys on wallet ID and tolerates nothing above a euro:

SELECT w.wallet_id, w.balance - j.mirrored_balance AS gap
FROM   wallets w JOIN journal_rollup j USING (wallet_id)
WHERE  ABS(w.balance - j.mirrored_balance) >= 1.00;

Reconcile the mirrors nightly, not monthly.

The drift window is the exposure. A nightly three-way check — float, wallet ledger, journal — shrinks the maximum undetected divergence from thirty days to one.

06 —

Anti-patterns

The generic AI dark mode this system exists to prevent:

  • Gradient text, gradient heroes. The hero is type, space, and at most the dot grid.
  • Glassmorphism / backdrop blur. Surfaces are opaque; hairlines separate them.
  • Drop shadows for elevation. Borders carry elevation. The inset top highlight is the whole shadow budget.
  • Thin display type on dark. Light strokes shimmer on near-black — 550–650 or nothing.
  • A second accent. Semantic colours are state, not decoration.
  • Decorative glow. No halos, no neon, no pulsing dots.
