§ 01

Document mode

Masthead — .dds-eyebrow / .dds-title / .dds-subtitle / .dds-meta

Opens every document. One optional <em> accent in the title; the meta bar carries facts (author, date, status), not decoration.

Hero header — .dds-hero + .dds-statuscard

When a long headline would leave the right margin empty, don't widen the title — keep text-wrap: balance and fill the sidenote gutter with a status/facts card. Best for a brief: state and gates at a glance. Eyebrow goes above, the .dds-meta bar below.

Verdict — .dds-verdict[data-label]

Closes a document that lands on a conclusion. The label states what the box is: Recommendation, Finding, Open question. Never a dark inverted slab.

The drift is bounded and explained.

Register rows — .dds-reg-row / .dds-dot / .dds-reg-meta

Status dot + label + mono metadata. Dots for rows; chips for inline labels — one per context, never both. The pending dot is a hollow ring — not-started / blocked / awaiting (dot-only, no chip form).

§ 03

Shared utilities

ClassEffectUse for
.dds-monoMonospace stackAny machine value in flowing text
.dds-numTabular numeralsEvery digit column; combine with right alignment in tables
.dds-smallcapsSmall caps + trackingOccasional serif emphasis (Document mode only)
.dds-rightRight alignmentNumeric cells outside .dds-table
.dds-evidenceMono 12px mutedfile:line / ticket / verified-date citations

Links are ink with a muted underline in both modes, turning accent on hover; keyboard focus draws a 2px accent outline. Both come free from the stylesheet — never restyle them per page.
