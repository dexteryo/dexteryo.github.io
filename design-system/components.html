Document mode

Masthead — .dds-eyebrow / .dds-title / .dds-subtitle / .dds-meta

Opens every document. One optional <em> accent in the title; the meta bar carries facts (author, date, status), not decoration.

§ 03

Layout (v2)

Shell — .dds-page

Fluid full width with a clamp(16px, 4vw, 64px) gutter, capped at 1920px. Prose inside holds --dds-measure (72ch); figures, tables, grids and panels take the whole width. Add .dds-wide to lift the measure from a paragraph that genuinely needs it.

Contents rail — .dds-layout / .dds-toc / .dds-main

A sticky contents rail from 1200px; below that it folds into a wrapped list above the content. The links work with no script; an optional inline IntersectionObserver adds .is-active to the current section's link (this page uses it).

Markup
<div class="dds-layout">
  <nav class="dds-toc" aria-label="Contents">
    <div class="dds-toc-h">Contents</div>
    <ol><li><a href="#context">01 Context</a></li> …</ol>
  </nav>
  <main class="dds-main">
    <section class="dds-section" id="context">…</section>
  </main>
</div>

These read the mode-resolved aliases (--dds-ink, --dds-surface, --dds-rule, --dds-r…), so the same markup renders square on paper in Document mode and rounded on the cool ground in Panel mode.

Decision record — .dds-adr

Header: id, title, status pill (accepted · proposed · superseded · rejected), date and owner. Body: Context / Decision / Consequences columns that stack on narrow screens; consequences use .dds-pros (+) and .dds-cons (−).

ADR-015

Export the ledger nightly to S3

Proposed2026-10-07 · data-eng
Context

Finance queries hit the primary during month end.

Decision

A nightly ledger-export job writes Parquet to S3.

Consequences
  • No analytical load on the primary.
  • Reports lag by up to a day.

§ 05

Shared utilities

ClassEffectUse for
.dds-monoMonospace stackAny machine value in flowing text
.dds-numTabular numeralsEvery digit column; combine with right alignment in tables
.dds-smallcapsSmall caps + trackingOccasional serif emphasis (Document mode only)
.dds-rightRight alignmentNumeric cells outside .dds-table
.dds-evidenceMono 12px mutedfile:line / ticket / verified-date citations

Links are ink with a muted underline in both modes, turning accent on hover; keyboard focus draws a 2px accent outline. Both come free from the stylesheet — never restyle them per page.
